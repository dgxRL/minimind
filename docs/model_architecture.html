MiniMind Model Architecture

Source of truth: model/model_minimind.py and model/model_lora.py. All parameter counts below are computed analytically from MiniMindConfig defaults.

1. Overview

MiniMind is a decoder-only causal transformer following the Llama recipe: pre-norm RMSNorm SwiGLU FFN RoPE + GQA + QK-Norm tied embeddings and an optional Mixture-of-Experts FFN. It subclasses HuggingFace PreTrainedModel / GenerationMixin and returns MoeCausalLMOutputWithPast.

PropertyValue (default MiniMindConfig)
Hidden size768

Attention heads8 query / 4 KV heads (GQA, n_rep = 2), head_dim = 96

Positional encodingRoPE, theta = 1e6, max positions 32768; optional YaRN scaling at inference (inference_rope_scaling, factor 16 over 2048 base)
NormalizationRMSNorm (eps = 1e-6, computed in fp32, cast back to input dtype), pre-norm; plus QK-norm on head_dim
ActivationSiLU, SwiGLU FFN; intermediate_size = ceil(768·π/64)·64 = 2432
AttentionCausal; Flash via F.scaled_dot_product_attention when available and enabled, else eager with manual causal mask
MoE (optional, use_moe=True)4 experts, top-1 per token, normalized top-k weights, router aux-loss coef 5e-4
Dropout0.0 (attn & residual)
Word embeddingsTied: lm_head.weight ≡ model.embed_tokens.weight

3. Attention — Attention (GQA + QK-Norm + RoPE)

RoPE with optional YaRN (inference scaling)

Frequencies f(i) = θ−2i/d are precomputed for max_position_embeddings = 32768 positions. With inference_rope_scaling, frequencies are interpolated with a linear ramp γ ∈ [0,1] between β_fast = 32 and β_slow = 1 wavelength boundaries:

f'(i) = f(i) · ((1 − γ) + γ / factor)   # factor = 16, base context 2048 → 32768
cos/sin tables doubled on the last axis (cat), scaled by attention_factor = 1.0
At decoding time the model slices freqs_cos[start_pos : start_pos + seq_len] — the KV-cache position offset comes from past_kv[0].shape[1]. Buffers are non-persistent and re-computed if lost to meta-device init (transformers ≥ 5.x guard).

4. Feed-Forward — FeedForward (SwiGLU) and MOEFeedForward

Dense SwiGLU

down_proj( act_fn(gate_proj(x)) * up_proj(x) )
# 768 → 2432 → 768, no bias
# act_fn = SiLU (hidden_act)

MoE (use_moe = True)

scores = softmax(gate(x_flat))              # (T, 4)
w, idx = topk(scores, k=1)                  # top-1
w = w / w.sum(-1, keepdim=True)             # norm_topk_prob
y[tok] += w · expert_e(x[tok])  for routed e
aux_loss = num_experts · coef · Σ_e load_e · mean_score_e
        # coef = 5e-4; load_e = one_hot(idx).mean over tokens
Unrouted experts still receive a zero-weighted grad hook in training mode: y += 0 · Σ params — keeps DDP gradients defined. The router gate is a plain Linear(768 → 4), and aux_loss is attached as an attribute read back in MiniMindModel.forward.
