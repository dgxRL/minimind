Kimi Delta Attention

KimiDeltaAttention: a gated delta-rule linear attention with per-channel decay. It replaces softmax attention in 6 of 8 layers when use_kda=True. Instead of a KV cache that grows with every token, it keeps one 96 × 96 state matrix per head.
