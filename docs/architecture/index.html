Each page draws one part; all numbers are for the default config (hidden 768, 8 layers, vocab 6400). For how the training and inference code is organised, see code_structure.md.

Config knobs added for KDA and AttnRes

FieldDefaultMeaning
use_kdaFalseTurn on the hybrid; trainers expose it as --use_kda 1 and save as *_kda.pth
full_attn_interval4Every N-th layer keeps full attention; ≤ 0 means all layers are KDA
layer_typesderivedExplicit list of "kda" / "full_attention"; overrides the interval
kda_num_heads / kda_head_dim8 / 96KDA heads; state per head is head_dim × head_dim
kda_conv_size4Kernel width of the causal short convolution on q, k, v
attn_nope= use_kdaFull-attention layers skip RoPE; KDA carries position information
use_attnresFalseReplace residual adds with Block Attention Residuals; --use_attnres 1, saved as *_attnres.pth
attnres_block_size2Sub-layers per AttnRes block (attention and MLP count separately): 1 = Full AttnRes, 2 = one block per layer
