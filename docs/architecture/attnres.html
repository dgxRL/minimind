Attention Residuals

Block AttnRes (arXiv:2603.15031) replaces the fixed residual sum with softmax attention over depth: each sub-layer chooses how much of the embedding and of each earlier block to read. Enabled with use_attnres=True; works with any combination of use_moe and use_kda.

Cost

Parameters: 1,536 per op (pseudo-query + key norm), 17 ops, 26,112 in total (+0.04%). The KV / KDA cache is unchanged: AttnRes mixes only along depth, within each token, so incremental decoding needs no extra state.

Eager mode runs each source's weighted add as its own elementwise kernel, which a model this small notices. torch.compile fuses them, so train AttnRes models with --use_compile 1.
