Cache & Generation

What the model carries between decoding steps, and why the hybrid uses less memory at long context.

Cache layout

Cache size per sequence

Attention: 2 × 4 heads × 96 × 2 bytes = 1,536 B per token per layer. KDA: 8 × 96 × 96 × 4 B (fp32 state) + 3 × 2304 × 2 B (conv) = 308,736 B per layer, independent of T.
